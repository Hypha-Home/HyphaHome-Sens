Betrieb

Ein ausgeschalteter Sensor wird weder gelesen noch gemeldet: Die Oberfläche zeigt ihn als deaktiviert, Home Assistant als nicht verfügbar. Die Änderung gilt sofort, ein Neustart ist nicht nötig.

Glättung

Der Sensor wird jede Sekunde gelesen und schwankt dabei leicht. Hier legen Sie fest, aus wie vielen Messungen ein Mittelwert gebildet wird
1 bedeutet keine Glättung, 60 mittelt über eine Minute. Die Änderung gilt sofort.

Temperaturkalibrierung

Tragen Sie Paare ein: links der Wert, den dieser Sensor angezeigt hat, rechts der Wert eines Referenzthermometers daneben. Durch alle Punkte wird eine Ausgleichsgerade gelegt, mit der jede weitere Messung korrigiert wird. Ein Punkt verschiebt die Anzeige um einen festen Betrag, ab zwei Punkten wird auch die Steigung mitbestimmt. Punkte aus deutlich verschiedenen Temperaturen bringen dabei mehr als mehrere aus derselben Stunde.

Die Luftfeuchte wird mitkorrigiert: Sie ist ein Verhältnis zur Temperatur, verschiebt sich diese, gilt der alte Feuchtewert nicht mehr. Dafür braucht es keine eigenen Punkte.
